# loop-forge

Designs and generates an agentic loop for a project.

Install from the marketplace in this repository:

```
/plugin marketplace add YOUR-ORG/loop-forge-marketplace
/plugin install loop-forge@loop-forge-marketplace
```

Everything the skill needs travels with it — templates, reference docs, and `forge.py`, which
depends only on Python and pyyaml. Start with `skills/loop-forge/SKILL.md` for the workflow,
and `skills/loop-forge/reference/verifier-patterns.md` for the part that actually matters.
